# Guides, Arabic editions and the evidence quiz

This release expands the three existing mystery files with clearly labelled critical interpretations, introduces three source-led beginner guides, and provides Arabic editions of the three files. English and Arabic editions retain their own canonical URLs and link to each other through hreflang and a visible language switch.

The five-question evidence quiz is available in both languages. It distinguishes what the cited records support, rather than claiming to detect whether an arbitrary video is authentic. An attempt is held only in page memory. Each answer includes an explanation and a link to its case-file evidence; the result includes a review, restart and optional sharing. Without JavaScript, the questions and expandable answers remain in the HTML.

Thirteen 1200×630 PNG sharing cards use original geometric layouts and page-specific titles. They are generated from the editorial data and cached by signature and PNG digest. Arabic cards use a font with Arabic/Latin coverage and libraqm shaping. Social buttons use the production canonical, even in previews; no social service is called automatically.

The main navigation, footer, home discovery panel, source-check pages and related links expose the new destinations. Arabic pages include localized navigation, copy notifications and analytics-consent controls. The privacy policy now describes page-local quiz state and optional sharing; its update date reflects that substantive policy change.

## Content sources

- The existing publisher records and interviews remain the basis of the mystery files. New interpretation sections explicitly distinguish critical readings from creator-confirmed answers.
- The analog-horror guide references Kris Straub's January 13, 2016 production note and a direct FANGORIA interview published November 19, 2026.
- The ARG guide uses the 2006 IGDA ARG SIG white paper hosted by contributor Christy Dena, and Straub's creator-side project listing.
- The source-checking guide references the Verification Handbook's video chapter. It uses the handbook's principles rather than reproducing historical software interfaces as current instructions.

## Validation

- Generated site: 124 pages, 89 catalog videos, 98 indexable sitemap URLs.
- Static checks include local destinations and fragments, source/video identity, JSON-LD and CSP hashes, reciprocal language links, PNG dimensions and digests, sharing URL encoding and no-JavaScript quiz explanations.
- Python catalog/preview regressions and Node search/saved-list/quiz-state regressions remain part of `npm test`.
- Browser review covers correct and incorrect answers, final review, restart, result-sharing controls, Arabic source-file navigation and narrow layouts.

See the README for the build dependency and the data-entry contracts. No hosting migration, advertising integration or YouTube upload is part of this release.
